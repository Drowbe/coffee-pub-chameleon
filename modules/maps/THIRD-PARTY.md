## Where the Noto Sans map glyphs came from

The six `.pbf` files under `public/maps-glyphs/` (the map style asks for them as `/maps-glyphs/{fontstack}/{range}.pbf`, font stacks
`Noto Sans Regular` and `Noto Sans Medium`, ranges 0-255, 256-511 and 8192-8447) are the ready-made glyph files of the **Protomaps
basemaps-assets** project, <https://github.com/protomaps/basemaps-assets>, folder `fonts/`. That project's README says they are
"PBF glyphs generated by font-maker" (<https://github.com/maplibre/font-maker>) from Noto Sans, and that the folder's licence is the SIL
Open Font License (`fonts/OFL.txt`).

Proved on 2026-11-13 by downloading each file from the project's published address
(`https://protomaps.github.io/basemaps-assets/fonts/<font stack>/<range>.pbf`) and from its `main` branch on raw.githubusercontent.com:
all six are byte for byte the same as ours (same SHA-256, below). Our `public/maps-glyphs/OFL.txt` is byte for byte the same as the
project's `fonts/OFL.txt` (SHA-256 `7713cfc8e3c36d5ec4aa3d6cffe7500a1b3310f8a86d914b8ea09c2a9dee7c2d`); it begins "Copyright 2022 The Noto Project Authors (https://github.com/notofonts)".

Not proved: the project has no version number we could read (the GitHub API was not reachable from the build machine), so the pin is the
file hashes and the `main` branch on that date, not a release. We also could not prove which Noto Sans font release font-maker was run
on; the copyright line above is the project's own. The official openmaptiles/fonts release v2.0 and the MapLibre demo-tiles glyphs also
carry a "Noto Sans Regular", but their files are different (different bytes); ours do not come from them. "Noto Sans
Medium" is in neither of those.
