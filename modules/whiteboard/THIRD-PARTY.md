# Third-party code in the Whiteboard module

**Audience:** whoever redistributes or audits the Whiteboard module.

None. The board is drawn with the browser's own HTML and SVG, and every line of its code is the module's own.

If a library is added (a drawing library such as PixiJS, MIT), it goes in `src/` as a plain file with its licence header
kept, and is listed here with its version and licence.
